# Nexify - Multi-Service Platform Website

A modern, premium, highly interactive multi-service business website with a GitHub-inspired dark developer aesthetic.

## Features

- 🎨 **Dark-first interface** with green accent
- 🎯 **Fully responsive** - works on all devices
- 🚀 **3D interactive hero** with Three.js
- 📱 **Mobile-optimized** with hamburger menu
- ✨ **Scroll animations** with Intersection Observer
- 📊 **Animated statistics** counters
- 🎭 **Interactive service cards** with hover effects
- 📝 **Clean, maintainable code** structure

## Technologies Used

- HTML5
- CSS3 (Custom properties, Grid, Flexbox)
- JavaScript (ES6+)
- Three.js (3D animations)
- Google Fonts (Inter, Space Grotesk)
